A rent payment system developed in Java Netbeans requires using MVC architecture, Singleton pattern, and a TXT file to process the rent payment business logic for users called RESIDENT. I need you to provide the complete package structure including the Utils package to place the Singleton model class. The model should be Resident with attributes: Resident ID, name, and rent months. The system will be implemented using GUI with Frm classes. One of the Frm classes will be the rent payment screen, which must automatically display the Resident ID, the monthly rent value, and a combo box allowing selection from 1 to 12 months. Each time a month is selected, the rent value should update, and finally a button to make the payment. In the TXT file named rentalValue.txt located in the src folder, the monthly rent value should be stored (only a number), and through this text document the rent value will be obtained or modified. The ID should be auto-generated but starts with hardcoded data like 001, as well as the names.
