Lista de comandos para ejecutar tu proyecto Node.js

Abrir CMD y navegar a la carpeta del proyecto

cd C:\Users\ESPE-LABS\Contacts\Documents\contact\contact_app_js


Instalar las dependencias necesarias (solo la primera vez)

npm install express mongoose cors


Ejecutar el servidor

node server.js


(Opcional) Ejecutar el servidor usando el script definido en package.json

npm start


Nota: Este comando funciona si usas código con import/export y "type": "module" en package.json.
Para tu código con require y "type": "commonjs" es mejor usar directamente node server.js.

Para detener el servidor

Presiona Ctrl + C en la ventana CMD.
