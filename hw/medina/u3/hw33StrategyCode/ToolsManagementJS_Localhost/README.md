# ToolsManagementJS (localhost)

## Instalar
```bash
npm install
```

## Ejecutar
```bash
npm run start
```

## Abrir
- http://localhost:3000

## Mongo (opcional)
Variables de entorno:
- MONGO_URI (default: mongodb://127.0.0.1:27017)
- MONGO_DB (default: toolsdb)
- MONGO_COLLECTION (default: tools)
