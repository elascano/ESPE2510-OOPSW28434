# Guía de instalación de Electron

Para instalar y ejecutar el proyecto con Electron, sigue estos pasos:

## Pasos para instalar Electron

1. **Inicializa el proyecto con npm:**

   Si aún no has inicializado tu proyecto, ejecuta el siguiente comando en la terminal desde la raíz de tu proyecto:

   ```bash
   npm init -y

npm install electron --save-dev

npm start
